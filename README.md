# FPV Cigarette

A lit cigarette held in front of the camera in first-person view: it burns down, the ember glows and flickers, and smoke drifts off the tip. Taking a drag makes the ember flare, and a moment later you exhale a cloud of smoke.

## Use
Make a macro with `/cig`. The first press lights the cigarette; every press after that takes a drag. The cigarette only shows when the camera is zoomed all the way in (first person).

| Command | Effect |
|---|---|
| `/cig light` / `/cig drag` / `/cig out` | light it / take a drag / put it out |
| `/cig auto` / `/cig always` | show in first person only (default) / at every zoom level |
| `/cig move` | drag it into place with the mouse; run again to lock |
| `/cig scale 0.3-3`, `/cig reset` | change the size / reset position and size |
| `/cig time <seconds>` | how long one cigarette burns (default 300) |
| `/cig calibrate` | tell the addon you're in first person now (only needed on clients without `GetCameraZoom`) |
| `/cig status` | print the current state |

## How it works
- **Textures:** all 32-bit TGA files with an alpha channel, generated by `python tools/make_textures.py` (needs numpy and Pillow). The script also writes `Geometry.lua` and `tools/preview.png`.
  - `Textures/cigarette.tga`: a flipbook of 4×2 cells, 256 px each. Frame 1 is unlit; frames 2–8 burn down.
  - `Textures/smoke.tga`: a flipbook of 4×4 cells, 128 px each, showing one puff from start to fade.
  - `Textures/ember.tga`: a glow drawn with additive blending.
- **Flipbooks:** frames are picked with `SetTexCoord` on every update (`Logic.CellTexCoords`), so the addon doesn't depend on the `FlipBook` animation type, which some clients may lack.
- **Smoke:** a pool of 56 textures, used as particles. There are three kinds: the thin stream from the tip, the puff when you light it, and the exhale. Each particle rises, grows, sways and plays the smoke flipbook (`Logic.ParticlePose`).
- **First person:** uses `GetCameraZoom()` when the client has it. Otherwise it estimates the camera distance by hooking `CameraZoomIn` and `CameraZoomOut`.
- **Parenting:** the frame is parented to `WorldFrame` at BACKGROUND strata, so it stays visible when the UI is hidden with Alt+Z and every window draws above it.

## Replacing the art
Draw your own sheets with the same layout. Each must be a power-of-two size, 32-bit TGA with alpha, frames left to right then top to bottom. If the cigarette tip moves, update the per-frame tip positions in `Geometry.lua` (or the constants in the script). The game only loads new texture files after a full restart; `/reload` is not enough.
